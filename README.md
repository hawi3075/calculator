# 🧮 Magic Animated Calculator

A sleek, modern web calculator built with Vanilla HTML, CSS, and JavaScript. This project features a high-end Glassmorphism design and smooth micro-animations.

## ✨ Features
* **Glassmorphism UI**: Uses backdrop-blur and semi-transparent backgrounds for a modern "Apple-style" look.
* **Animated Interactions**: 
  - **Button Hover**: Elements lift slightly and glow when hovered.
  - **Button Click**: Physical "press" effect with scaling animations.
  - **Entry Animation**: The entire calculator smoothly slides up when the page loads.
* **3D Depth**: Multi-layered box shadows create a realistic sense of depth on the screen.
* **Responsive Design**: Works perfectly on both desktop and mobile screens.
